Mon portfolio

Ce site est mon portfolio personnel, créé avec Streamlit. Il présente mon profil, mes compétences et mes projets. Il comprend aussi une page de résultats du TP2 avec un graphique. Le site est disponible en français et en anglais.

- **Site :** https://portfolio-z58mgs5dsvcmdcvpun9wrc.streamlit.app/
- **Dépôt GitHub :** https://github.com/lala-love01/portfolio

## Lancer le site sur un ordinateur

Installe Python, puis ouvre un terminal et exécute :

```bash
git clone https://github.com/lala-love01/portfolio.git
cd portfolio
python -m pip install -r requirements.txt
streamlit run app.py
